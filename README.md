# 🚦 Traffic Sign Classifier

A deep learning–based project that automatically identifies and classifies traffic signs from images using convolutional neural networks (CNNs). This model is trained on labeled traffic sign datasets and can accurately predict sign categories such as speed limits, warnings, mandatory signs, prohibition signs, and more.

---

## 📌 Project Overview

The **Traffic Sign Classifier** is a computer vision project built to recognize traffic signs using machine learning. It leverages image preprocessing, feature extraction, and a trained CNN model to classify traffic sign images into predefined categories.

This project can be used for:

- Driver-assistance systems  
- Autonomous vehicles  
- Road safety applications  
- Educational and research purposes  

---

## 🧠 Key Features

- 🖼 **Image preprocessing:** resizing, normalization, color-space conversion.
- 🧬 **CNN-based architecture:** learns complex image features.
- 🎯 **High-accuracy classification:** trained using supervised learning.
- 📊 **Model evaluation:** accuracy, confusion matrix, loss curve.
- 🔍 **Real-time prediction support:** classify uploaded or live camera images.
- 🚗 **Multi-class output:** supports dozens of traffic sign categories.

---
